This project is a reproducer of a regression in Gradle 9.2.0 resulting in `ConcurrentModificationException` error determining task dependencies.

# Gradle 9.1.0

The reproducer uses Gradle Wrapper for Gradle 9.1.0. Run

````
./gradlew :application:quarkusBuild -s
````

to verify the build succeeds with Gradle 9.1.0.

# Gradle 9.2.0

To reproduce the issue, upgrade the wrapper to Gradle version 9.2.0 with

````
./gradlew wrapper --gradle-version 9.2.0
````

and run

````
./gradlew :application:quarkusBuild -s
````

The build will fail with the following error

````
$ ./gradlew :application:quarkusBuild -s
````
